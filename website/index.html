Questions fréquentes

C'est gratuit ?

Oui ! GiftBlox est totalement gratuit. Pas de limite, pas de paywall. On veut juste rendre les communautés meilleures.

Comment les membres gagnent des points ?

Via la récompense quotidienne `/daily`, le parrainage, les quêtes et bientôt via l'activité sur le serveur.

Puis-je personnaliser la boutique ?

Actuellement les articles sont prédéfinis, mais la personnalisation via le panel admin arrive bientôt.

Mes données sont-elles sécurisées ?

Absolument. Connexion via OAuth Discord, base de données chiffrée, et aucun partage de données avec des tiers.
